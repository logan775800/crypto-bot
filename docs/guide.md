# Cryptocurrency_bot 使用指南

> 每个功能只回答三件事：**命令怎么打**、**按钮在菜单第几层**、**点进去怎么用**。
> 按钮路径都数得出点几下。

**最快上手**：直接发币名就能查价，例如 `BTC`、`eth`、`pepe`。
记不住命令就发 `/menu`（功能菜单）或 `/commands`（全部命令按钮面板，点了直接执行）。

## 📅 多日涨跌榜

回答「这 3 天谁涨得最多」。

**命令**

```
/rank 3            3 日榜，默认只看热榜（成交额前 50）
/rank 7            7 日榜
/rank 3 全部        不限热榜，两百多个币全排
/rank 7 币安 现货    只看币安现货
/top 3             和 /rank 3 一样
```

天数写「3日」「7天」都认。

**按钮**：`/menu` → 📊 行情 → 📅 3日涨跌榜（两下）

**出结果之后**，消息底下五排按钮：

| 按钮 | 作用 | 快慢 |
|---|---|---|
| 3日 / 7日 / 14日 | 换时间窗口 | 秒出 |
| 🔥 热榜前50 / 全部币 | 热榜只在成交额前 50 名里排，一屏都是认得出的币 | 秒出 |
| 三家 / Bybit / 币安 / OKX | 换交易所 | 首次要等十几秒 |
| 永续+现货 / 永续 / 现货 | 换市场 | 首次要等十几秒 |
| ℹ️ 口径 | 翻到背面看细账：怎么算的、扫了多少、剔掉了什么 | 秒出 |
| 🔄 重扫 | 强制拉最新（不点的话 5 分钟内用同一批） | 十几到几十秒 |

**口径**：N 日涨跌幅 = 现价 ÷ N 天前的日线收盘 − 1。终点用现价不是昨收，
否则今天的行情完全不体现。日线按 UTC 0 点切。

**和 `/upstreak` 不是一回事**：那个要求连续几天同向。一个币 3 天累计涨 30%
但中间回调过一天，在连涨榜里根本不存在。

## ⚖️ 多空比极值榜

全市场现在谁最一边倒。

**命令**

```
/lsr            币安永续，最看多 / 最看空各 3 个
/lsr bybit      换 Bybit
/ratio BTC      单个币查一次
```

**按钮**：`/menu` → 📊 行情 → ⚖️ 多空比极值榜（两下）

**怎么读**：多空比 = 做多账户数 ÷ 做空账户数（**账户数，不是持仓金额**）。
小于 1 的比值人脑读不出量级，所以每行直接翻译成倍数：

```
RE     0.46   多头 31%   空头是多头的 2.2 倍
DOGE   2.91   多头 74%   多头是空头的 2.9 倍
```

底下带一行 BTC 作参照——没有参照系读不出「这算不算极端」。

**这是散户情绪指标，常作反向参考**，一边倒的那侧往往是被收割的那侧。
但它只是情绪不是信号：配合资金费率（`/fex`）一起看才有意义——
散户极度看多 + 资金费率高得离谱 = 多头在付钱硬扛。

**只换所，不合并三家**：同一时刻实测 ETH 在币安是 2.69、OKX 1.33、Bybit 1.86。
各家统计的是自己那批用户，合成一张榜排出来的是「哪家用户最偏多」，
不是「哪个币最被看多」。

## 💣 清算地图

各个价位上估计堆了多少待强平的仓位，出图。

**命令**

```
/liqmap TRUMP     默认近 7 日
/liqmap BTC 30日   换窗口：1日 / 7日 / 30日
/lmap SOL         短写法
```

**按钮**：`/menu` → 📈 分析与图表 → 💣 清算地图（两下，再点币种）

**出图之后**：【1日 / 7日 / 30日】换窗口、【ℹ️ 口径】、【🔄 重算】、【🪙 换币】。
图片消息改不了图，所以换窗口会发一张新的，原来那张还在，方便对比。
图下面直接给上下各 3 个最密集的价位区间和距现价百分比。

> ### ⚠️ 这是模型估算，不是交易所数据
>
> **没有任何交易所公布「某个价位挂着多少待爆仓的仓位」**——那是每个账户的
> 私有信息。市面上的清算地图（包括 CoinGlass 那张）都是推算的。
>
> 推算方式：每根 K 线期间**新增**的持仓量当成建在那根的典型价上（减仓不算，
> 那是平仓不产生新爆仓位）；永续里每份持仓同时是一多一空，所以两侧都留下位置——
> 多头爆仓 = 建仓价 × (1 − 1/杠杆)，空头 = × (1 + 1/杠杆)；
> 按 5x/10x/25x/50x 分配权重落进价格桶，现价已经越过的一侧抹掉。
>
> **哪些是假设**：杠杆分布是估的（交易所不公布谁开了几倍）、建仓价用 K 线典型价、
> 没算维持保证金率，所以估出的位置比真实爆仓价略远一点。全部印在【ℹ️ 口径】里。

**怎么用**：密集区是**磁吸位**，价格容易被推过去扫一轮再走。
**止损别正好压在柱子上**——那正是最容易被插针带走的位置。
它说的是「这里有人会被平」，不是「价格会到这里」，别当信号用。

## 🎮 虚拟交易（练手不碰真钱）

$10,000 起步，真实行情、真实滑点费率、会爆仓、扣资金费。

**打开交易台**：`/vtrade`，或 `/menu` → 🎮 虚拟交易台。开合约五步全是按钮：
选币 → 方向 → 杠杆 → 保证金 → 市价/限价。刻意和实盘交易台走同一套路径，
这样练出来的手感能迁移。

**常用命令**

```
/vopen BTC long 1000 10       开多（1000U 保证金 10 倍）
/vclose BTC                   平仓
/vpos                         持仓 + 浮盈 + 爆仓价
/vbuy BTC 1000                现货买入        /vsell BTC all  卖出
/vorders                      我的委托单      /vcancel 3      撤单
/vhistory                     胜率历史
```

**止盈止损**（合约和现货都能设）

```
/vtpsl BTC tp=70000 sl=60000    有合约仓就设合约仓，没有就落到现货持币
/vtpsl BTC 现货 sl=60000         两边都有时，指名道姓给现货
/vtpsl BTC sl=0                 填 0 = 清除
```

按钮：交易台里持仓那行自带【平50%】【全平】【改止损】，
现货那行自带【卖50%】【全卖】【🎯止盈损】。后台每 60 秒检查，触及自动平仓并通知。

现货触发时会**全卖**，并先撤掉这个币挂着的限价卖单——不撤的话被锁住的币出不来，
止损就只卖得动一部分。

## 📊 复盘（这是唯一真能提升胜率的功能）

```
/rstats 30 v         近 30 天虚拟盘成绩单
/rstats 30 v ai      让 AI 从数字里挑你的行为漏洞
```

胜率、盈亏比、期望值、最大回撤，再按**币种 / 多空 / 持仓时长 / 时段**拆开。
加 `ai` 之后它会指出类似「平均持仓 8 分钟且短持仓大幅亏损 = 追高进场后被立刻打脸」
这种模式。虚拟盘这条路不需要任何密钥，私聊直接发。

## 其它常用

| 命令 | 干什么 |
|---|---|
| `/oc BANK` | 查链上代币价格（交易所还没上的币，发合约地址也行） |
| `/scan` | 机会扫描，按**可交易性**排序，不是涨幅榜 |
| `/fex` | 资金费率极端榜（全市场跨所，按结算周期归一到日化） |
| `/microcap` | 微市值扫描：流通市值 < 300 万而且真买得到的币 |
| `/achart BTC 1h` | 标注图表：均线、摆动高低点、前高前低、止损带画在图上 |
| `/checklist` | 合约交易检查清单（开仓前自查） |
| `/commands` | 全部命令的按钮面板，按分类列，点了直接执行 |
| `/changelog` | 这一版更新了什么 |

**群里用法**：@ 机器人 或回复它的消息就能直接对话问问题。
直接发币名查价在群里也能用。
